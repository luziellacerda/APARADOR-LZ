DEPENDENCIAS E DISTRIBUICAO - LZ GAMES 1.3.0

APLICATIVO
Compilar e embutir o codigo nao muda a titularidade ou as licencas dos
componentes. Nao foi atribuida uma nova licenca ao codigo da aplicacao.
O codigo desta versao acompanha a release em um arquivo source.zip.

FFMPEG, FFPROBE, X264 E X265
A release offline do GitHub compila os componentes a partir dos fontes
fixados em ci/dependencies.lock.json, com a receita ci/Build-FFmpeg.sh.
Os binarios antigos de 2018 nao sao usados na release publica.
Consulte TERCEIROS-FFMPEG.txt para versoes, licencas e avisos completos.
O FFmpeg desta compilacao usa componentes GPL e --enable-gpl.

Os fontes exatos, licencas, receita e configuracao dos componentes
estao em FFmpeg-corresponding-source.tar.xz, junto do instalador em:
https://github.com/luziellacerda/APARADOR-LZ/releases/tag/v1.3.0
O aplicativo chama FFmpeg/ffprobe como processos separados.
Uma compilacao manual com outros componentes precisa de seus proprios
avisos e fontes correspondentes; este texto nao certifica outro pacote.
Referencia do projeto: https://ffmpeg.org/legal.html

RUNTIME MICROSOFT
.NET Framework 4.8 e Windows PowerShell 5.1 sao componentes do sistema;
nao sao copiados para este instalador. Permanecem sujeitos aos termos
dos respectivos fornecedores. O EXE usa Windows Forms e
System.Management.Automation e nao exige scripts externos de aplicacao.

INSTALADOR NSIS
O instalador usa NSIS, Modern UI 2 e compressao LZMA. O manifesto da
release registra a versao e o hash do compilador usado. Os termos
fornecidos por essa instalacao do NSIS estao em TERCEIROS-NSIS.txt.
Referencia do projeto: https://nsis.sourceforge.io/Docs/

ASSINATURA DIGITAL
Aplicativo e instalador nao possuem assinatura Authenticode nesta
entrega. Nao foi adquirido certificado nem configurado editor verificado.
